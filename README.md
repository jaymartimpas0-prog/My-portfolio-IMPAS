# My Personal Portfolio

My personal portfolio website built with React and Vite. It automatically fetches and displays my public repositories directly from my GitHub profile.

## Tech Stack

- React
- Vite
- CSS
- GitHub API

## How to Run Locally

1. Clone the repository:
   git clone https://github.com/jaymartimpas0-prog/My-portfolio-IMPAS.git

2. Install dependencies:
   npm install

3. Start the dev server:
   npm run dev
